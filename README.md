# Madani.store Player

Official Windows installers and signed automatic updates for **Madani.store Player**.

## Download

[Download the latest Windows installer](https://github.com/KarimGaber0/madani-store-player-releases/releases/latest)

Run `MadaniStorePlayerSetup.exe` once to install the edition that supports automatic updates. Future versions download in the background and install after all player windows close. A small notification tells you when an update is ready.

This repository contains release downloads only. Application source code and signing keys are not published here.
